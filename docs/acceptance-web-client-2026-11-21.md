Проверка прав и конфликтов прошла через публичный API. Два одновременных создания с одинаковым ID дали одну строку. При одновременной правке администратором и участником сервер вернул 200 и 409. Отсутствующая запись и карточка другой тестовой компании вернули 404. Недопустимые дата, сумма и стадия вернули 422. После очистки необязательного поля сервер вернул null.

Telegram подтвердил приём текста и файла для владельца A1 Admin. В исходящей истории у обеих отправок есть идентификатор сообщения провайдера. Ранее созданные тестовые записи со статусом «В очереди» повторно не отправлялись.

Во время проверки OPS исполнитель n8n перестал принимать задания. После согласованного перезапуска с пустой очередью зарегистрировался JS Task Runner и завершил новые задания. Ошибки конкретных обработчиков указаны ниже.

При имитации временной ошибки опроса результата браузер повторно запросил исходный идентификатор. Рабочее действие было отправлено один раз.

Четыре типа карточек открыты клавишей Enter из списка и канбана. Проверены конфликт в двух открытых редакторах с сохранением ввода и переключение компании при задержанном ответе предыдущей компании.

## Что остаётся для приёмки

- По строкам «Только интерфейс» подтверждены открытие режима, передача параметров и обработка тестового ответа. Для приёмки нужны итог конкретного рабочего запуска и проверка созданного документа, задачи, записи или доставки.
- В конфигурации рабочего n8n нет подключения типа Google Sheets OAuth2. Для чтения предоставленной приватной таблицы требуется авторизация аккаунта Google с доступом к ней. В реестре A1 Admin не найдены подключения Сбера и HRIS. Проверка Яндекс Директа по поручению владельца завершена на двух черновиках.
- Приоритет серверных исправлений — подтверждать дату следующего контакта по записи лида, сумму оплаты по записи обязательства и итог встречи по сохранённому событию. В задачах нужны файл, шаблон документа и обязательные параметры. Для HR и юридического отдела требуется содержательный результат дочернего обработчика. Для ежедневного дайджеста нужна проверка подготовки сообщения и квитанции о доставке.
- Проверены сохранение подраздела конфигурации и онбординг. Восстановление доступа остаётся проверить на отдельной тестовой учётной записи.
